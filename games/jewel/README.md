# Jewel Coloring

Мозаїка з самоцвітів у браузері: вибираєш колір, ставиш камені на клітинки з
його номером, і картинка поступово проявляється. Чотири рівні складності,
рівень із будь-якого свого фото, монети за пройдені картинки й магазин.

Відкрити: `games/jewel/` через локальний сервер або GitHub Pages.

## Як це працює

Рівень ніколи не зберігається як набір пікселів. Зберігається **картинка**
(вбудований малюнок або одне JPEG з галереї) — а сітка щоразу будується з неї
наново:

```
пікселі → усереднення по клітинках → k-means у просторі Lab → палітра + номери
```

k-means саме в Lab, а не в RGB, бо в RGB алгоритм охоче зливає кольори, які око
розрізняє (і навпаки) — картинка виходить каламутною. Усе згенеровано з
фіксованим seed, тож одне фото на одній складності завжди дає той самий рівень:
інакше збережений прогрес не збігся б із картинкою.

Дві додаткові речі роблять палітру грабельною:
- кольори, ближчі за 7 одиниць Lab, зливаються — два невідрізнимі відтінки в
  палітрі це баг, а не складність;
- кластери, менші за 0.4% картинки, переносяться на найближчий колір — інакше
  палітра забивається кольорами на три клітинки роботи кожен.

## Складність

| | Сітка | Кольорів | Монети | Підсвічування |
|---|---|---|---|---|
| Легко | 24×24 | 8 | ×1 | так |
| Норм | 36×36 | 14 | ×1.6 | так |
| Складно | 48×48 | 20 | ×2.4 | ні |
| Експерт | 64×64 | 28 | ×3.4 | ні |

На «Легко» і «Норм» клітинки обраного кольору підсвічуються — грати можна не
вчитуючись у номери. На «Складно» і «Експерт» підсвічування немає: орієнтир
лише номер у клітинці, який видно, коли наблизити.

Одну картинку можна проходити на всіх чотирьох складностях — це чотири різні
рівні з окремим прогресом.

## Свої фото

«Мої фото» → «Зробити рівень з фото» → вибрати кадр (перетягнути, колесо або
два пальці — масштаб) → назва → складність.

Фото не виходить із пристрою: воно кадрується в canvas, стискається до
512×512 JPEG і лежить у `localStorage` браузера. Звідти ж береться картинка
для будь-якої складності. Це стосується й картинок, згенерованих у Grok чи
деінде — збережи в галерею і завантаж сюди як звичайне фото.

## Монети

- +2 монети за кожні 100 правильно поставлених каменів — щоб велика картинка
  платила ще під час гри;
- за пройдений рівень — від розміру й складності, помножено на точність
  (помилки зʼїдають до 45% нагороди);
- повторне проходження вже пройденої картинки — чверть ціни, щоб перепроходити
  одне й те саме не було вигідніше, ніж грати нове.

Витрачати: підказки (ставлять один правильний камінь), бомби (до 25 каменів
обраного кольору), форми каменів (мозаїка, сердечка, зірочки) і теми тла.
Порожня кишеня — підказка коштує 25 монет напряму, бомба 60.

## Керування

| | |
|---|---|
| палець / миша | ставити камені, з протягуванням |
| два пальці | масштаб і переміщення |
| колесо, подвійний клік | масштаб |
| «Рука» | переміщення одним пальцем |
| «Уся картина» | показати рівень цілком |
| `H` / `B` / `F` / `Esc` | підказка / бомба / уся картина / вийти |

## Файли

```
js/quantize.js   картинка → сітка: усереднення, k-means у Lab, палітра
js/level.js      правила: складності, постановка каменя, нагорода, збереження
js/shop.js       гаманець, магазин, підказки й бомби
js/art.js        вбудовані малюнки (векторні, тому працюють на будь-якій сітці)
js/render.js     canvas: камені, номери, підсвічування, масштаб і панорама
js/app.js        екрани, ввід, імпорт фото — усе, що торкається DOM
```

Перші три файли не знають ні про DOM, ні про canvas — саме тому правила гри
перевіряються без браузера:

```bash
node test/jewel.test.js
```

Прогрес, гаманець і фото лежать у `localStorage` під ключами `arcade:jewel:*`.
Збереження рівня пакується по шість клітинок на символ: рівень 64×64 займає
менше кілобайта.
