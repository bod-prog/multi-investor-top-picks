# Arcade — набір для створення ігор

Усе, що потрібно, щоб робити ігри прямо в цьому репозиторії: рушії завантажені
з GitHub у `vendor/`, спільний каркас — у `lib/arcade.js`, два робочі приклади —
у `demos/`. Без npm, без збірки, без CDN: сторінка відкривається як є, працює
офлайн і на GitHub Pages.

## Що всередині

```
games/
├── index.html          хаб: список ігор + самоперевірка всього набору
├── lib/arcade.js       спільний шар: input, sfx, loop, store, масштабування
├── lib/arcade.css      спільний вигляд (та сама палітра, що й у головному застосунку)
├── vendor/             бібліотеки з GitHub + ліцензії + MANIFEST.md
└── demos/
    ├── hopper/         2D-раннер на Phaser 3
    └── spin/           3D-сцена на three.js
```

Повний список бібліотек, версій, хешів і ліцензій — у
[`vendor/MANIFEST.md`](vendor/MANIFEST.md).

## Jewel Coloring

[`jewel/`](jewel/) — гра, а не демо: мозаїка з самоцвітів із чотирма рівнями
складності, рівнями з власних фото, монетами й магазином. Правила винесені в
модулі без DOM і перевіряються через `node test/jewel.test.js`. Деталі — у
[`jewel/README.md`](jewel/README.md).

## Запуск

Через `file://` модулі й шрифти блокуються браузером, тож потрібен будь-який
локальний сервер:

```bash
python3 -m http.server 8080
# відкрити http://localhost:8080/games/
```

Сторінка `games/` сама перевіряє набір: чи піднявся Phaser, чи імпортується
three.js, чи є WebGL, чи грає jsfxr, чи підвантажився шрифт, чи живий каркас.
Якщо щось червоне — гра теж не працюватиме, і рядок скаже чому.

## Каркас `Arcade`

| API | Для чого |
| --- | --- |
| `Arcade.Input` | клавіатура + тач + геймпад за однією моделлю дій: `held('left')`, `pressed('action')`, `axis()`, у кінці кадру — `endFrame()` |
| `Arcade.Sfx` | `define('jump', 'jump')` один раз, далі `play('jump')`; `toggle()` вимикає звук і памʼятає вибір |
| `Arcade.Loop` | фіксований крок (`new Arcade.Loop(dt => {...})`), пауза разом із вкладкою, без «спіралі смерті» після лага |
| `Arcade.Store` | `get/set` поверх localStorage, який може бути заблокований, і `best('game', score)` для рекордів |
| `Arcade.fit` | цілочисельне масштабування canvas — піксель-арт залишається різким |
| `Arcade.loadFont` | підвантаження `Press Start 2P` перед першим кадром |

Дії, які розуміє `Input`: `left`, `right`, `up`, `down`, `action`, `pause`,
`mute`, `touch`. На тачскріні ліва третина екрана — `left`, права — `right`,
центр — `action`.

## Нова гра

1. `cp -r demos/hopper demos/моя-гра` (2D) або `cp -r demos/spin demos/моя-гра` (3D).
2. Виправити відносні шляхи до `../../vendor/…` і `../../lib/…`, якщо змінилася глибина.
3. Писати логіку в `game.js` / `scene.js`.
4. Додати картку гри в `index.html` хаба.

Обидва приклади навмисно не мають жодного файлу-ресурсу: текстури малюються
кодом (`generateTexture`), звуки синтезуються (`jsfxr`). Це зручний старт —
ресурси додаються тоді, коли вони справді потрібні, а не «про всяк випадок».
